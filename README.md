# أَثَـر DZ | Athar DZ — المنصة الوطنية للسياحة الثقافية والصناعات الحرفية (69 ولاية)

### صفحات المنصة (9 صفحات مترابطة بالكامل)
- `index.html` — الصفحة الرئيسية الوطنية (الرؤية، 69 ولاية، المعالم المختارة، الإبداعات الحرفية، وبوابات المنظومة)
- `about.html` — صفحة «من نحن» (الرسالة الوطنية، الرؤية، ركائز المنصة، ونموذج الشراكات والتواصل)
- `explore.html` — استكشاف المعالم والفعاليات عبر 69 ولاية مع نموذج حجز متكامل (التاريخ، الفترة، عدد التذاكر، البطاقة الذهبية / CIB) وتوليد تذكرة QR
- `passport.html` — جواز السفر الثقافي الرقمي وألعاب الاكتشاف التفاعلية
- `marketplace.html` — المتجر الحرفي الوطني (شراء مباشر أو استبدال بالنقاط مع شهادات أصالة QR)
- `login.html` — بوابة تسجيل الدخول وإنشاء الحسابات للزوار والحرفيين ومنظمي الفعاليات
- `visitor-dashboard.html` — فضاء الزائر ومحفظة التذاكر والطلبات والهدايا
- `artisan-dashboard.html` — لوحة تحكم الحرفيين ومنظمي الفعاليات (B2B SaaS)
- `admin-dashboard.html` — لوحة الإدارة الوطنية والرقابة عبر 69 ولاية

### المزايا التقنية
- **تغطية شاملة لـ 69 ولاية جزائرية** (من 01 أدرار إلى 69 الأبيض سيدي الشيخ) في قوائم البحث والحجز والتسجيل.
- **تعريب وترجمة 100%** (العربية `RTL`، الفرنسية `LTR`، الإنجليزية `LTR`) لجميع الواجهات والبيانات والنوافذ.
- **11 صورة حقيقية عالية الدقة** مدمجة محلياً في `assets/images/`.

### نظام الخطوط العريق والحديث (Cultural & Modern Typography)
- **للغة العربية:** دمج خط **عارف رقعة (`Aref Ruqaa`)** للشعار وهوية العلامة، وخط **أميري (`Amiri`)** العريق لعناوين المعالم والحرف والمتاحف، مع خط **`IBM Plex Sans Arabic`** العصري لواجهات الحجز ولوحات التحكم.
- **للغتين الفرنسية والإنجليزية:** دمج خط **`Cinzel`** و**`Playfair Display`** للعناوين التراثية الفاخرة مع خط **`Plus Jakarta Sans`** للواجهات التفاعلية.
